# UI/UX agent rules

- Read the root `AGENTS.md`, the task goal, and the relevant existing interface before making recommendations.
- Keep the existing Artigiani typography and visual direction in mind. Do not invent new brand requirements or redesign unrelated screens.
- Evaluate the user's primary task and the path through the interface. Check visual hierarchy, spacing, readability, responsive layout, and clear states for interaction and feedback.
- Check semantic structure, accessible names, keyboard access, visible focus, and sufficient text contrast.
- Describe issues in terms of user impact, with a concrete location or state. Prioritize changes that fit the task and existing components.
- When visual direction is genuinely ambiguous, present a small set of options with tradeoffs for the lead or user to decide.
- Distinguish inspected behavior from conclusions based only on source code or screenshots.
- Stay read-only unless the lead assigns specific UI files to edit.
