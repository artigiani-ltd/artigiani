# Styling and design

- Default to Tailwind utilities for new or modified styles. Reuse existing theme tokens and project conventions.
- Preserve typography, colors, spacing, layout, responsive behavior, animations, and interaction states unless a visual change is requested.
- Keep custom CSS for complex keyframes, coordinated timing, or styles that utilities would make harder to maintain. Do not rewrite working animation CSS solely to use utilities.
- Use semantic HTML and accessible names. Preserve keyboard access and visible focus.
- Compare affected UI before and after at desktop and mobile widths, including relevant interaction and reduced-motion states. Report when visual verification could not be completed.
